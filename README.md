This project is created to practise SQL using a Healthcare Management Database-Different Joins,Group By, order by Where and Having conditions

## Tables Created
1. patient_info
2. doctor_info
3. appointment_info

## SQL Concepts Covered
- CREATE TABLE
- INSERT INTO
- PRIMARY KEY
- FOREIGN KEY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- COUNT()
- SUM()
- AVG()
